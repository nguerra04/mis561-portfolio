MIS 561 - Data Visualization, Completed on September 24th, 2026, [a link to my published Tableau workbook](https://public.tableau.com/views/PowerBITrainingCertifications_17902758013200/PowerBIStory?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link), In Flex 3/4, I manually used lookup formulas in Excel to match information across separate tables before bringing the data into Tableau. Power BI can handle this by creating relationships between tables based on a shared field, without requiring me to manually add the matching values into one dataset. Next time, I would use Power BI because it keeps the tables connected while reducing the amount of manual lookup work and the risk of mismatched records.
